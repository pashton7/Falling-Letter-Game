# Falling Letter Game
Small physics engine using C# and Winforms, with the intention being a quick week long project O(n) complexity wasn't heavily considered rather the programming doing what was intended over performance and speed.

# Features
- Uses .Net Framework
- Use of SAT (Separating Axis Theorem) to calculate collisions
- Utilizes WinForms

# How to Play
When the executable is run it will read all keyboard inputs and create physics based falling blocks that cover your screen
